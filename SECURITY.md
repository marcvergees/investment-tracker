# 🔒 Política de Seguretat

## Versions amb Suport

Aquest projecte manté les versions actives següents:

| Versió | Suportada |
| --- | --- |
| 1.2.x (Web SPA & GitHub Pages) | ✅ Sí |
| 1.1.x (Streamlit Core) | ✅ Sí |
| < 1.0.0 | ❌ No |

---

## Privacitat i Processament de Dades

**ETF Portfolio Tracker & Backtester** està dissenyat seguint el principi de privacitat per disseny (*Privacy by Design*):
1. **Zero telemetria de dades d'inversió**: Totes les carteres que crees, els teus capitals inicials i les teves assignacions de fons es processen únicament de forma local a la teva màquina (a la carpeta `saved_portfolios/` o al `localStorage` del teu navegador).
2. **Cap connexió a servidors de tercers** excepte per descarregar les sèries històriques de preus públics de Yahoo Finance.

---

## Reportar una Vulnerabilitat

Si descobreixes una vulnerabilitat de seguretat o una fuga de privacitat en aquest repositori:
1. **NO** creïs un issue públic.
2. Envia un correu electrònic amb la informació detallada a l'equip mantenidor del projecte o utilitza la pestanya **Security Advisories** de GitHub.
3. Si us plau, inclou una descripció de la vulnerabilitat, passos per reproduir-la i possibles solucions.

Agraïm la teva col·laboració en fer d'aquesta eina una solució segura per a tots els inversors.
